Loads legacy unmodded Balatro run saves with modern Steamodded by restoring missing save-state fields. Also includes
  selected-hand score preview, projected round total, optional 10x score-animation speed-up, and optional 2x shop-entry
  animation speed-up. Supports English and Simplified Chinese.

  Tested with Balatro 1.0.1o, Steamodded 1.0.0~BETA-1814a, and Lovely 0.9.0. Please back up saves before using different
  game or loader versions.
