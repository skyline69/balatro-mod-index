# Targeted Rerolls

A quality-of-life shop search mod. Select one or more cards, set the money you want to keep, and let the mod perform Balatro's normal rerolls until a target appears, the next paid roll would cross the reserve, or you press **STOP**.

- Search targets by name, key, or category; selections persist between runs.
- Uses vanilla `reroll_shop()` rather than spawning cards or changing card pools.
- Supports compatible bignum money providers through `to_big()`.

## Requirements

[Steamodded](https://github.com/Steamodded/smods) and [Lovely](https://github.com/ethangreen-dev/lovely-injector).
