(For a better experiencie, install the Warp Zone mod too, alongside this mod)

This mod was meant to be an dlc for the vanilla game, keeping some balance and unique mechanicsto enhance a longer playtime in the game :3

This mod adds:
- 150 brand new jokers + some extras hidden
- 6 difficulties higher than Gold stake
- 10 brand new Challenges
- 5 new decks
- 8 vouchers
- 52 new consumables (in 3 new kind of categories)
- 6 seals
- 8 booster packs
- 12 tags
- 1 sticker
- 5 editions
- and some micelaneous extras (also some kinky [not nsfw] sprites, but you must active a hidden option)

This mod is compatible with any other mod that you have installed

the mod is translated into
- English
- Español
- Português

==================================================================================================================================================================================

Version 1.5.0

What changed?

   Added 75 new Jokers to the mod.

   The Collection menu now automatically sorts modded Jokers by their rarity level.

   Pandora: Added the new decks to its possible effects.

   the black market

Mechanics & Reworks

   Showman: All modded Jokers and consumables are now 100% compatible with Showman and can appear as duplicates in the shop and booster packs if the effect is active.

  Painter: Functionality completely redesigned (Rework).

  Battle Pass: Functionality redesigned to now refund the money from your last purchase.

  Benchwarmer: Scoring priority modified. Chips are now granted directly by the played card instead of the Joker, similar to Raised Fist.

   TMTRAINER (Passive): Added a global effect that gives any Joker a 10% chance to become a TMTRAINER when generated in the shop.

Balance Changes

   Jok: Rarity increased to Zenith tier [Buff].

   Gray Seal: Improved activation/reward parameters [Buff].

  Dispenser Machine: Improved reward parameters [Buff].

   The Champion: Now increases the required blind size [Nerf], but grants an additional +$2 of interest in return [Buff].

  Economic Recession: Reduced the exponential multiplier from 0.4 to 0.1 [Nerf].

  The Pact: The blind size increase is now compatible with the Blueprint Joker [Nerf].

Bug Fixes

   UNO and Inverse Tarot Packs: Fixed an issue that prevented all cards from their respective pools from appearing in booster packs.

   Miner: Fixed a crash when attempting to destroy cards. Now correctly destroys Stone cards.

  Platanito: Fixed a fatal crash when the Joker attempted to destroy itself.

  Paratrooper: Fixed an issue where chips would start decaying in the background even if you didn't own the Joker.

  The Pact: Fixed a bug that permanently locked the buy button in the shop if you purchased an item while holding this Joker.

  TMTRAINER: Fixed a generation bug that caused all Jokers in the same shop to share the same sprite (they were not seeded properly).

   The High Priestess (Joker): Fixed the effect not properly decreasing money by 20%.

  The High Priestess (Inverse Tarot): Fixed the generation effect; it now creates the Black Hole correctly.

  License Plate: Readjusted trigger timing. It now increments its value before evaluating the hand, allowing the XMult to affect the same hand that triggered it.

  The Hanged Man (Inverse Tarot): Now correctly targets and randomizes 2 specifically selected cards from hand, rather than random cards.

   Ice Cream Sandwich: Fixed a bug where the Joker wasn't granting the corresponding money.

  Cashback: Fixed a critical bug that prevented its effect from triggering.

   Battle Pass: Fixed an issue where the internal counter would increase even if the Joker was not in your possession.

   Telescope: The target poker hand now uses a fixed seed, preventing it from incorrectly changing when reloading the run.

   Pisces: Fixed a bug where the target would visually get stuck on "High Card" and fail to grant the score when played.

Black Market

  Evil Meter: Now correctly starts at -2%.

  Evil Meter: Defeating the first Boss Blind now adds 20% to the current evil instead of strictly setting the value to 20.

   Reroll Consistency: The amount of items for sale no longer randomly fluctuates when rerolling in the same shop.

  Reroll Cost: Fixed a bug where rerolling was free; it now correctly consumes Tokens.

  Reroll Scaling: The reroll cost now scales correctly (+1 Token per use).

   Smuggler: Reroll prices now properly update and reduce when this Joker is in play.

  UI Softlock: Fixed a bug where closing the Black Market with the "Esc" key locked the button, preventing it from being reopened.

   Pool Control: Leo will now only appear in the Black Market if the pool allows eternal Jokers (Black Stake or higher).

  Pool Control: Supreme Seed, Ascended Beanstalk, and Zenith rarity Seed/Beanstalk variants were removed from the Black Market.

Texts & Interface (QoL)

   Zenith Rarity: The rarity tag on cards now respects the game's language instead of always displaying in English.

   TMTRAINER: Random descriptions were shortened (5 to 15 characters) to prevent text from overflowing the screen.

  Miner: The visual "+5" upgrade message now pops up over the Joker instead of triggering on every evaluated Stone card.

   Late Shipment: The text now updates in real-time upon discarding rather than waiting until the end of the round.

   Lucky Seven: Added a dynamic counter to the description that displays how many 7s have been played in total.

   Doppelganger: Now displays the full description and stats of the Joker it is currently copying.

  Sticker Fever: The term "tag" was translated to "etiqueta" in the Spanish localization.

   Life Assurance: The description now states "prevents death" instead of "game over".

   Wolf of Wall Street: Description rephrased for better clarity.

   Space Deck: Fixed a typo in the percentage (said 75% instead of the correct 25%).

   Granny Joker: Removed outdated text indicating a ^3 chips increase; the inactive description was simplified to solely mention its destruction by straights.

  Cashback: Removed an extra leftover line of text from the description.

  Viking: Fixed incorrect use of plurals.

   Prosopagnosia: Fixed the plural for the face cards reference.

   Cookies: The description now changes dynamically to visually indicate whether the cookies are active or inactive.

   Aries: The description now clarifies that hands "scale one more time" rather than "evaluate one more time".

   Leo: Removed the word "base" from the first description line to avoid confusion.

   Leo and Virgo: Replaced the word "pegatina" with "sticker" in the Spanish localization.

  Cancer: Updated text to "chances to prevent death" instead of "prevent a game over".

  Stamp and Battle Cards (Football, Battle, American Football): Standardized the text format to "each [rarity] Joker gives X[#] Mult" to maintain consistency.
