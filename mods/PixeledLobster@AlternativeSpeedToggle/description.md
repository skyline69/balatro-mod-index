# Alternative Speed Toggle

Adds a small draggable checkbox to the in-run HUD that forces the game speed to a
value of your choice (`0.5x` by default) while you are actually playing a blind, and
leaves your own `Game Speed` setting alone everywhere else. A shortcut key (`S` by
default) toggles it without touching the mouse.

The override applies during hand selection, drawing and playing, and stops for the
shop, blind select, the end-of-round cash out, booster packs and every menu — there
you keep the speed you set in the game's own options. Your saved `Game Speed` is never
overwritten.

A second speed selector is added to the game's own Settings → Game tab, right next to
the vanilla one, so you can pick the override speed independently. The shortcut key is
rebindable from the same screen.

Lovely only — Steamodded is not required.
